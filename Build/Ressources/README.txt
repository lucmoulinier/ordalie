
Ordalie (Ordered Alignment Information Explorer)
Version 3.5 2026/11/16

Luc Moulinier & CSTB

https://bigest-icube.fr/ordalie


You just downloaded the Ordalie program.

Ordalie views, edits and analyses multiple sequence alignments together
with the 3D structures of their proteins. It reads and writes the MACSIM
format, as well as FASTA, MSF and CLUSTAL (ALN) files.

Installation
------------

In a terminal, go to this directory and type:

    ./install.tcl

then follow the instructions. The script needs tclsh. If ./install.tcl
does not start, type instead:

    tclsh install.tcl

Once Ordalie is installed, this setup-<platform> directory is no longer
needed and can be deleted.


Uninstallation
--------------

To remove Ordalie, run the script uninstall.tcl that the installation
copied into the ordalie directory, for example:

    ~/ordalie/uninstall.tcl
